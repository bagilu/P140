# P140 公車資料工作台 V0.003

## 先選對資料

工作台與前台分開：`admin.html` 是編輯器；`index.html` 是既有全路網模擬。下載或預覽都不會修改線上正式路網。

第一次開啟工作台，預設是310官方圖片辨識草稿，包含24個去程站名、待核對的反向回程站序，以及兩端各4班發車時刻。所有經緯度與途中時間留空，不把景點中心當作站牌。來源圖片也保留在工作台。

「開啟完整示範資料」可以測試整套編輯流程；此資料是虛構的市區310，並非實際310。請勿將這份示範誤當官方路線。

## 01 來源

填路線簡稱、完整名稱、穩定識別碼、顏色、來源名稱／網址／取得日期。官方生效日期若有提供，寫在附註。檢查原圖與待確認事項。

先在ChatGPT提供官方圖表及工作台的「AI辨識提示詞」。取得 `recognitionVersion=1.0.0` JSON後，透過檔案或貼上匯入。本版不會直接把圖片送給AI，也不使用AI API金鑰。

本機自動儲存不等於永久備份。請定期「下載草稿」，它會保存候選來源、位置、道路、必經點、鎖定、確認狀態、時間及來源圖片。更換電腦時匯入草稿即可。清除瀏覽器網站資料會移除本機儲存。

## 02 站點

選去程或回程，檢查站序。支援移動、改名、新增與刪除站點；變動站序會要求重新確認並清除需要重估的逐站時間。

先匯入已下載的政府站牌JSON，工作台會在本機比對，不會保存政府API金鑰。支援TDX欄位，例如：

```json
[
  {
    "StopUID": "TEST_STOP_001",
    "StopName": {"Zh_tw": "測試站"},
    "StopPosition": {"PositionLon": 121.6, "PositionLat": 23.99}
  }
]
```

以上僅格式範例，不代表實際站牌位置。也可匯入 `{ "stops": [{ "id": "…", "name": "…", "coord": [121.6,23.99], "source": "…" }] }`、含stopuid/stopname的ArcGIS JSON或GeoJSON。

本包未附可用的政府候選快照。此階段實際查詢TDX需認證，其他公開來源未能取得可靠回應，因此沒有杜撰座標補入。需先取得可用的站牌資料，才能批次比對。

「比對本站名清單」只為唯一同名且尚未定位的站點提出位置；多個同名站保留全部候選，不自行選道路側邊。近似名稱只列出候選，不自動套用。選候選後請核對地圖，再按「確認此站位置」。也可輸入經緯度、點地圖或拖曳微調。

修改位置會使相鄰道路失效，解除相鄰路段鎖定，並清除逐站時間；其他道路保留。去回程站牌各自處理。

## 03 道路

本方向所有站點有位置後，按「產生本方向道路候選」。OSRM依站點與必經點順序回傳沿街道折線。它是汽車道路候選，並不保證是實際公車走法。檢查後逐段或整批確認。

走錯路時，選路段、按「在地圖加入必經點」，依行駛順序點道路，再按「重算此路段」。必經點不會成為公車站。已完成路段可鎖定，整方向重算時保留；移動其端點會使鎖定失效，以免沿用不相容路徑。

使用OSRM公開示範服務的原型限合理非商業使用，請求以單一佇列間隔至少1.1秒，結果快取於本機。服務沒有可用性保證。請求逾時、無路由、起訖變動或回應缺少折線時保留原草稿，不以直線替代。正式長期大量使用應換成自建或有服務承諾的路由服務。

## 04 班次

每班設定起站發車時間及適用星期，1為週一、7為週日；同方向同時刻重疊星期不可重複。

道路完成後可產生逐站預估時間。初始為道路旅行時間乘1.5，加各站停靠時間；管理者可調整累積到站、離站分鐘。這不是實測模型，也不是官方到站時刻。表格可輸入小數分鐘，匯出時轉整數秒；起站兩值為0。

第一版工作台每方向只有一組時間設定，多班次共用；前台資料契約仍支援多組timingProfiles。遇到一條路徑多組時間的既有JSON，本版拒絕編輯，不會默默覆寫成一組。

## 05 預覽與匯出

有位置、道路、班次與有效時間後，即可預覽尚未確認的草稿。預覽頁明確標記為編輯草稿，不改正式路網；所有資料存於同來源本機儲存，請勿用來輸入私人位置。

正式匯出需確認每個站位、每個道路段及站序，並通過時間單調性、來源與引用檢查。匯出的是 `schemaVersion=1.0.0`、routes含單一路線的JSON。草稿中的編輯狀態不全部進入發布資料，請同時保存草稿。

「合併多條已完成路線」檢查各檔格式與routeId唯一性，產生一份bus_network.json。此操作不會上線；部署時再替換前台data/bus_network.json。合併工具統一站名前後顯示時間為30／15秒。

## 官網改版時

新官方圖表重新交給AI辨識，保留方向id或名稱，貼到「更新新版官方資訊」，先比對再套用。

- 只改班次：保留已確認站位、道路及逐站時間。
- 站序改變：保留可對應的同名站及未受影響的相鄰道路，清除逐站時間，要求重新確認站序。
- 去回程在新資料中交換順序：優先以穩定id／名稱對應，不以陣列位置強配。
- 支援復原最近10次本次開啟期間的操作；跨工作階段的版本備份請使用下載草稿。

這不是完整的版本差異審核系統。來源圖片本身不會由工作台重新OCR；辨識及官方版本判斷仍需人工核對。
